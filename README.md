# Light minimal

A light, minimal theme for Claude Code in the Claude desktop app: a soft lavender
background, purple-tinted near-white surfaces, quiet grey text and one calm purple accent. Your
messages show as flat white cards with a thin lavender border. It sets itself at the start of
every session and stays light even when the Mac is in dark mode.

## Install

At the prompt of a terminal session:

```
/plugin install light-minimal --marketplace tortaise-stack/light-minimal-theme
```

Answer `y` to add the marketplace, then press Enter to install for your user.

From a shell:

```
claude plugin install light-minimal --marketplace tortaise-stack/light-minimal-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then
Plugins, Add marketplace with `tortaise-stack/light-minimal-theme`, then Add plugin.

The theme shows in the desktop and mobile apps; the terminal keeps its own colours.
